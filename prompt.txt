3. Fitur detail tugas dan surat
Ketika guru membuka tugas, informasi yang ditampilkan sebaiknya meliputi:
Informasi	Keterangan
Nomor surat	Nomor surat asli
Perihal	Judul atau isi pokok surat
Tanggal surat	Tanggal penerbitan
File surat	Dokumen asli yang bisa dibuka
Pemberi tugas	Wakasek yang meneruskan tugas
Instruksi	Arahan yang harus dilakukan
Prioritas	Biasa, Penting, Segera
Batas waktu	Tenggat pengerjaan
Status	Belum Diproses, Diproses, Selesai

Guru harus bisa menekan tombol Lihat Dokumen untuk membaca surat asli dalam browser tanpa harus mengunduhnya.

5. Endpoint API untuk guru
Karena kamu sudah menggunakan struktur /api/v1, endpoint-nya bisa dibuat seperti berikut:
Method	Endpoint	Fungsi
GET	/api/v1/disposisi/inbox	Melihat tugas yang diterima
GET	/api/v1/disposisi/:id	Melihat detail tugas
GET	/api/v1/disposisi/:id/dokumen	Melihat dokumen surat asli
PATCH	/api/v1/disposisi/:id/tindak-lanjut	Mengubah status dan mengisi laporan
GET	/api/v1/disposisi/:id/riwayat	Melihat riwayat tugas

Endpoint tersebut sebenarnya sudah sebagian besar ada dalam rancangan backend-mu. Jadi, tidak perlu membuat modul baru khusus guru.

Contoh request ketika guru mulai mengerjakan:
PATCH /api/v1/disposisi/25/tindak-lanjut


{
  "status": "Diproses",
  "catatan": "Sedang melakukan pemeriksaan komputer."
}


Contoh request ketika guru menyelesaikan tugas:
{
  "status": "Selesai",
  "catatan": "Ditemukan 3 komputer mengalami kerusakan pada power supply."
}


Contoh response:
{
  "success": true,
  "message": "Tindak lanjut berhasil diselesaikan",
  "data": {
    "id_disposisi": 25,
    "status": "Selesai",
    "catatan": "Ditemukan 3 komputer mengalami kerusakan pada power supply.",
    "tanggal_selesai": "2026-11-19 10:30:00"
  }
}


6. Aturan akses yang perlu diterapkan
Ini penting supaya guru tidak bisa memanipulasi tugas milik pengguna lain.
- Guru hanya dapat melihat surat yang terkait dengan disposisi yang ditujukan kepadanya.
- Guru hanya dapat memperbarui status tugas miliknya sendiri.
- Guru tidak dapat membuat disposisi utama.
- Guru tidak dapat meneruskan tugas kepada guru lain, kecuali memang diberikan kewenangan khusus.
- Guru tidak dapat mengubah instruksi dari Wakasek.
- Setelah status Selesai, guru tidak dapat mengubahnya kembali.
Satu hal yang perlu dibedakan: ketika guru menekan Selesai, yang selesai adalah tugas guru tersebut, bukan otomatis seluruh disposisi Wakasek atau surat masuknya. Wakasek masih perlu memeriksa laporan guru dan menyampaikan hasil akhir kepada Kepala Sekolah.

Dengan begitu, alur tanggung jawabnya tetap jelas: Guru menyelesaikan tugas → Wakasek memverifikasi hasil → Kepala Sekolah memantau penyelesaian disposisi.
