# batavia - srikandiClone

React 19, TypeScript, Vite, Tailwind CSS 4, and React Router frontend for the school correspondence archive.

## Development

```sh
npm install
cp .env.example .env.local
npm run dev
```

Set `VITE_API_URL` to the backend API root (defaults to `http://localhost:3000/api/v1`). Sign in with an account managed by the backend.

## Production build

```sh
npm run build
npm run preview
```
